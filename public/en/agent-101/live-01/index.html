认知一

聊天的 AI，和干活的 AI，是两种东西

ChatGPT / Claude 网页版

  • 你问，它答
  • 一次一句，你来回搬运
  • 产出是一段文字

Agent（Claude Code / Codex / OpenClaw）

  • 你给目标，它执行
  • 自己拆步骤、自己用工具、自己跑完
  • 产出是一件做完的事

工具名字不用记，记住这条分界线就够了。

认知二

AI 不好用，是因为它不认识你

  • 它不知道你的职业、项目、口味、底线
  • 解法：写一份「自我介绍文件」，让每次对话自带背景
  • 我是谁 / 我在做什么 / 我喜欢什么样的输出

接下来现场演示：同一个问题，AI 认识我前 vs 认识我后。

现场带练 · 25 分钟

  • 2. 跟着我，写你自己的自我介绍文件

认知三

不是所有事都该交给 AI

值得交给 agent 的事，同时满足三条：

  • 重复发生 —— 每天、每周都要做一遍
  • 规则说得清 —— 你能给同事写成操作说明
  • 输入输出是文字或数据 —— 邮件、表格、文档、消息
