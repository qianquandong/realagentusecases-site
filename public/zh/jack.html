01 · AI 客服 · 线上运行SMS 可直接体验 · 中英西三语

AI 短信客服：回答咨询、查询档期、完成预约

问题

课程和业务咨询通过短信进来，重复问题要逐条回复；约一对一咨询时，还要来回确认双方时间。

交付

用 Cloudflare Worker 接收 Twilio webhook，OpenAI function calling 查询可约时间、把预约写入 D1，并向我发送客户、主题和时间摘要；对话支持中、英、西三语。

边界

只回答课程、服务和个人项目相关问题；超出范围就拒答；不确定时转给本人；不通过短信收款；用户明确选定时间后才写入预约。

架构与取舍

Twilio 只当短信管道，不依赖它的会话功能；对话和预约状态都在 Worker 和 D1 这一侧。写库只有一个入口——用户明确选定时间之后的那次 function call——所以模型答错的最坏结果是回错一句话，不会产生错误预约。另留了一个直连测试接口，不发短信也能跑通整条链路；换一份商家配置就能部署给下一家店。

Texas Instruments 供应链运营自动化

问题

排产、销售订单修正、供应缺口和周期报告，需要反复跨 SAP、Spotfire、Excel 与内部表单核对。

交付

用 Python 驱动独立 SAP GUI 会话，SQL 直连数据虚拟化层，Selenium 填写十几类表单，并从同一数据源生成报告、邮件和评审 PPT。

边界
