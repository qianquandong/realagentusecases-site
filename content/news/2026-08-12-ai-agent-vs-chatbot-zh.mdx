聊天机器人回应消息，AI agent 完成任务。这就是核心区别。聊天机器人回答一个问题就停下。AI agent 接过一个目标，规划步骤，调用像日历、数据库这样的工具，跨系统采取行动，一直做到任务完成——通常在有风险的步骤上留人工确认。

两者都用自然语言跟你对话，从外面看很像。区别在于消息发出之后发生了什么。这篇是大白话版，讲清那条藏在「我到底需不需要 agent」困惑背后的分界线。

## 聊天机器人在说，agent 在做

[IBM 把 AI agent 定义为](https://www.ibm.com/think/topics/ai-agents)「一个能代表用户或另一个系统自主执行任务的系统或程序」——关键词是*执行*。相比之下，[聊天机器人](https://www.ibm.com/think/topics/chatbots)本质上是一个对话界面：你发文字，它回文字。一个产出答案，另一个产出结果。

具体说：问聊天机器人「我周五日历上有什么」，好的会告诉你。让一个 agent「把周五下午清空，把 2 点那个挪到周一」，它会读日历、找出冲突、发出改期、再回来汇报——就是 [Issue #001 的 Gmail 三筛 agent](/zh/posts/2026-05-13-gmail-ai-agent/) 背后那套感知→判断→行动的循环。

## 聊天机器人擅长什么

聊天机器人是有边界对话的对的工具。规则型机器人走的是写死的决策树——网页版的「账单问题请按 1」。AI 聊天机器人（大模型驱动的那种）流畅得多，能应付开放式问题，但它的活儿仍是*回应*：答常见问题、查一笔订单、卡住时转人工。这不是缺点。对「你们退货政策是什么」，一个一轮就答完的聊天机器人正是你想要的——不用规划、不用工具、没有风险。

## 是什么让一个东西成为 agent

agent 比聊天机器人多了三样东西。[Google Cloud 把 agent 描述为](https://cloud.google.com/transform/ai-agents-evolving-with-google-agentspace)能够「自主采取行动、规划、推理，并选择使用哪些工具」。拆开看：

- **规划。** 它把一个目标拆成步骤，而不是回一条消息。「分析三个竞品并做一份幻灯」变成 调研 → 汇总 → 起草幻灯。
- **工具。** 它伸到聊天窗口之外——你的日历、一个数据库、网页、一个代码运行器。它怎么伸过去，通常靠 [MCP，agent 连接工具用的那个协议](/zh/news/2026-08-10-what-is-mcp-for-ai-agents/)。
- **跨步骤的行动。** 它执行、检查结果、调整，一直做到任务完成——并在整个过程中保持上下文。

这一转变最清楚的公开例子：2025 年 7 月 OpenAI 推出 [ChatGPT agent](https://openai.com/index/introducing-chatgpt-agent/) 时，用的说法是「打通研究与行动」——那个过去只会聊天的产品，现在能用自己的虚拟电脑浏览网页、填表单、跑代码、编辑表格。值得注意的是，它「在采取有后果的行动前会请求许可」——正是本站每篇稳妥搭建都保留的那道人工确认闸门。

## 灰色地带：「有 agent 味」的聊天机器人

这条线不是一堵墙。很多打着聊天机器人旗号的产品现在有了 agent 功能，很多 agent 也披着聊天界面。一个只答常见问题的客服机器人是聊天机器人；同一家的机器人若能查你的订单、发起退款、更新工单，那它在做 agent 的活。我们在客服场景里就画过这条线，[分流 vs 解决](/zh/news/2026-07-15-ai-agent-customer-support-triage/)：读取和路由是聊天机器人的形状；端到端解决是 agent 的形状。再往上一层，同样这条「行动还是作答」的判据，正是[agentic AI 与生成式 AI](/zh/news/2026-08-17-agentic-ai-vs-generative-ai/) 的分界。有用的判据不是盒子上的标签——而是这东西能*做*点什么，还是只能*说*点什么。

## 你到底需要哪一个

更强的自主性不自动等于更好。[Anthropic 的工程指南](https://www.anthropic.com/engineering/building-effective-agents)说得很直白：找「尽可能最简单的方案」，并指出大多数可靠的生产系统是可预测的*工作流*，而非全自主 agent——两者的差别在于「自主的程度」。如果你的问题是「快速答一个常见问题」，聊天机器人在速度和可预测性上胜出。如果是「跨我的工具完成一个多步任务」，你要的是 agent——而且要在[发送、付款、删除这类步骤上留人在回路](/zh/news/2026-08-13-human-in-the-loop-ai-agents/)。全是新概念？从 [Agent 101](/zh/agent-101/) 开始，再看[五种真正在职场站得住的 agent 模式](/zh/news/2026-08-04-ai-agents-for-work/)。

## FAQ

**AI agent 和聊天机器人有什么区别？**
聊天机器人回应消息，AI agent 完成任务。[IBM 把 agent 定义为](https://www.ibm.com/think/topics/ai-agents)一个自主执行任务的系统，而[聊天机器人](https://www.ibm.com/think/topics/chatbots)是一个回答完就停的对话界面。agent 会规划、用工具、跨多步行动；聊天机器人在说话。

**ChatGPT 是聊天机器人还是 AI agent？**
两者都是，看你怎么用。普通对话里它是聊天机器人。但 OpenAI 2025 年 7 月推出的 [ChatGPT agent](https://openai.com/index/introducing-chatgpt-agent/) 模式，让它能用自己的虚拟电脑浏览、填表、跑代码、编辑文件——那是 agent 行为。同一个底层模型两样都能干。

**AI agent 只是更聪明的聊天机器人吗？**
不是。差别不在智能，而在自主性和触达范围。再能干的聊天机器人也只是回答；agent 接过目标、调用工具、执行多步工作。[Google Cloud](https://cloud.google.com/transform/ai-agents-evolving-with-google-agentspace) 把 agent 框定为会规划、推理、选工具、采取行动的系统。

**我是不是总该用 agent 而不是聊天机器人？**
不——而且常常你不该。[Anthropic 建议](https://www.anthropic.com/engineering/building-effective-agents)用能work的最简单方案；答一个有边界的问题，聊天机器人更快也更可预测。只有当任务真的横跨多个步骤和工具时，才去找 agent。

**我怎么知道我在用的是 agent？**
问它能*做*点什么，还是只能*说*点什么。如果它在另一个系统里采取了行动——发一封邮件、更新一条记录、订一个时段——它就在以 agent 的身份行动。如果它只是返回一段文字让你去操作，那是聊天机器人。[Issue #001](/zh/posts/2026-05-13-gmail-ai-agent/) 展示了一个真在做前者的 agent。
