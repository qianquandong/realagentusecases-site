# Purpose

This page is the source of truth for AI-assisted SEO and GEO content production for Real Agent Use Cases.
Use it as the Knowledge Base for any AI SEO automation tool, content generator, keyword workflow, or LLM visibility monitor.
The goal is to help Real Agent Use Cases become a trusted bilingual publication for real AI agent workflows used by working professionals.

# Brand Positioning

Real Agent Use Cases documents real AI agent workflows that professionals can copy, adapt, and run at work.
The site publishes practical, tested use cases with prompts, tools, integrations, costs, setup steps, failure points, and improvements.
The brand should feel practical, honest, specific, and useful. It should not feel like generic AI productivity content.

# Core Promise

Every article should answer one practical question:
How can a working professional use an AI agent to complete a real workflow faster or better?

# Tone Of Voice

Write clearly and practically.
Use concrete details instead of hype.
Avoid generic phrases such as:
- Unlock your productivity
- Revolutionize your workflow
- In today's fast-paced world
- Seamlessly leverage AI
- Game-changing AI solution

Preferred style:
- Direct
- Specific
- Honest
- Slightly conversational
- Useful for someone who wants to build the workflow today

# Content Rules

Every article must include:
- Answer Summary or TL;DR
- Who this is for
- The real problem being solved
- Tools used
- Setup time
- Monthly cost
- Step-by-step setup
- Full prompt or reusable prompt template
- Example output
- What broke
- What changed after testing
- How to customize it
- FAQ
- Related internal links

Do not invent results, costs, screenshots, personal experience, or tool capabilities.
If information is missing, label it as an assumption or leave a placeholder for human review.

# Standard Article Template

## Answer Summary
Give the direct answer in 3-5 bullets. Make this easy for Google AI Overviews, ChatGPT, Perplexity, Claude, and Gemini to quote.

## The Problem
Describe the real workflow pain in plain language.

## Who This Is For
List the exact users who would benefit.

## What The Agent Does
Explain the agent's job in concrete terms.

## Tools Used
Include tool names, pricing, integrations, and alternatives.

## Setup Time And Cost
State the expected setup time and monthly cost.

## Step-By-Step Setup
Break setup into numbered steps.

## Full Prompt
Include the reusable prompt in a clean block.

## Example Output
Show what the finished agent produces.

## What Broke
List failure points, limitations, bad outputs, missing context, or security/privacy concerns.

## How To Improve It
Give practical improvements.

## FAQ
Add 5-8 natural-language questions that match how users ask LLMs and search engines.

## Related Workflows
Add internal links to related Real Agent Use Cases articles.

# Quality Bar

A page is publishable only if it helps a reader build or understand a real workflow.
Do not publish thin pages created only to target a keyword.
Do not publish articles that could apply to any AI tool, any brand, or any generic productivity blog.
The best Real Agent Use Cases article should feel like someone actually built the workflow, broke it, fixed it, and then handed the reader the working version.
